# Tarjetas con enlace actualizable

1. Abre https://supabase.com/dashboard/project/tmcccadamceaboyjwxlx/sql/new
2. Copia todo el contenido de `ACTIVAR-ENLACES.sql`, pégalo en el editor y pulsa **Run**.
3. Abre https://github.com/polaca1/rese-a-google/settings/pages y elige **Deploy from a branch → sidestore → /(root) → Save**. Espera a que la página https://polaca1.github.io/rese-a-google/link.html esté disponible.
4. En reviewNfcGo 6.0 abre **Clientes → un negocio → Enlace de tarjeta actualizable**.
5. Pulsa **Crear enlace**. Escribe ese enlace en la tarjeta una vez.
6. Después podrás cambiar el destino o desactivar la tarjeta desde la misma pantalla, sin regrabarla.

La dirección de destino de cada tarjeta es pública para quien tenga su enlace. Las cuentas, ventas y copias siguen privadas. La redirección necesita conexión a Internet. Las tarjetas antiguas con un enlace directo a Google deben regrabarse una vez para utilizar esta función.
